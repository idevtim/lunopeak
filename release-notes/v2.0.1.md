# LunoPeak v2.0.1

A privacy and safety release: turning an agent off now keeps LunoPeak from contacting that agent's services, and a few more buttons ask before they act.

## What's new

- **Turning an agent off now stops its network calls.** Before, switching Claude Code off in Settings hid its row, but LunoPeak still sent your Claude sign-in to Anthropic to fetch your plan limits. Now it doesn't fetch anything for Claude while it's off. Cursor works the same way: if Cursor is off, LunoPeak no longer reads its browser cookie to check your plan, even if "Cursor plan usage" was left on underneath. The provider status pages also follow your toggles now. LunoPeak only checks the status pages for agents you have on, and turning one back on doesn't recheck the others.

- **Your Claude sign-in stays out of the process list.** When LunoPeak renewed your Claude sign-in and saved it back to the Keychain, the new tokens briefly appeared on the command line of a helper process, where other programs on your Mac could see them. Now they're passed to the helper privately. Claude Code's Keychain entry already trusts that helper, so you still won't get a password prompt.

- **More buttons ask first.** "Fix automatically" on the Dependencies page now shows the exact command it will run and warns that it can change `package.json`, the lock file and your installed packages. "Stop" on a process in Hygiene, "Pull latest" on a repo, and "Unlock" on a worktree each ask before they run too. The stale-branch cleanup now also warns that commits you never merged or pushed are deleted along with the branch.

- **The privacy note in Settings is complete.** The About section used to say LunoPeak only went online to Anthropic and GitHub. It also talks to ChatGPT and Cursor for plan limits, to the public status pages, to GitHub for pull requests, and to your AI provider if you use the Assistant. The note now lists all of them and points to the privacy policy, which has the full details.

## One thing worth knowing

With Claude Code turned off, your Claude plan limits no longer appear anywhere, including the menu bar. If you were keeping Claude off only to hide its live sessions and still wanted its limits, turn it back on.

Codex and Cursor still read their own local files while they're off, and LunoPeak hides the result. Nothing from those reads leaves your machine.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)

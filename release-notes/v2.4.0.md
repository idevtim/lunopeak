# LunoPeak v2.4.0

A new Insights page gives you a GitHub-style Pulse for every repo you work in, all on one screen.

## What's new

- **Insights shows activity across all your repos.** Open it from Projects in the sidebar. It covers the last 24 hours, 7 days, 30 days or 90 days. The tiles at the top show commits (and how that compares with the period before), pull requests merged and still open, lines added and deleted, how many repos saw work, and the median time from opening a pull request to merging it. Below them are commits per day stacked by repo, pull request throughput, time to merge, lines added and deleted per day, and who committed. A list of every merged pull request comes next, then the repos that were quiet.

- **Each repo gets its own Pulse page.** Click a repo to see its summary in the same terms GitHub uses: how many authors pushed how many commits, how many files changed, and how many lines. It also shows its committers, commits and merged pull requests per day, and the files that changed most. It adds what GitHub can't see: how many Claude Code sessions you ran in that repo and what they cost.

- **Agent work is counted where it's marked.** When a commit names an agent such as Claude or Codex as a co-author, Insights counts it. So you can see how much of a repo's history went through an agent.

- **Commit numbers appear first, then pull requests.** Commits, lines and authors come from the git history already on your machine, so they show up within a second and work offline. Pull request numbers come from GitHub through the GitHub CLI and appear a few seconds later. If gh isn't installed or you're signed out, Insights says so and shows everything else.

## One thing worth knowing

Commit numbers come from your local copy of each repo, and LunoPeak never fetches for you. If you merge pull requests on GitHub and don't pull, those merges won't show in the commit counts until you fetch. Each repo's page says when it was last fetched, and turns amber after a day.

Days are your local calendar days, so the 7-day view starts at midnight six days ago. GitHub uses the last 168 hours, so expect small differences — a commit or two either way. In our testing, a busy repo came within 1 of GitHub's own counts for both commits and merged pull requests.

The agent count is a lower bound. Agents don't always mark themselves as co-authors, and some people turn that off.

Pull request numbers need the GitHub CLI (`gh`), signed in, and only cover repos whose remote is on github.com. They refresh every five minutes, or straight away with the Refresh button.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)

# LunoPeak v1.5.0

Click the menu-bar icon to open a redesigned popover with per-provider usage bars, today + 30-day spend, and quick actions back into the app. The rest of the app now adapts to whichever AI coding agents — Claude Code, Codex, Cursor — you actually have installed.

## What's new

### Redesigned tray popover
- Frameless, themed panel anchored under (or above) the tray icon, with frosted-glass chrome to match the rest of the app.
- Auto-hides on blur — click outside or hit the X to dismiss.
- Theme changes in Settings apply to the popover live.
- Subtle staggered entry animation; honors *Reduce motion*.

### Insight strip
- Surfaces the single most-pressing window across all your providers, color-coded green / amber / rose, with the reset time underneath.
- Dismissible with a click. A new, distinct insight surfaces fresh.

### Tabs + per-provider detail
- Overview tab plus one per enabled provider.
- Overview is a clickable grid; per-provider view shows Session (5h) and Weekly bars in the provider's color. Cursor shows "Active context" instead.

### Cost rollup + sparkline
- Today + last 30 days at the bottom of the panel, with a 7-day spend sparkline.

### Footer actions
- **Open LunoPeak** — brings the main window forward on the route you left it.
- **Settings** — jumps to Settings.
- **Quit** — clean exit.

### Adapts to your installed agents
- LunoPeak detects Claude Code, Codex, and Cursor at launch and tunes copy, empty states, and buttons to whichever combination you have.
- The Repo Detail "Open in agent" button opens whichever agent you actually use, not Claude by default.
- Views that only make sense for Claude Code (Memory, Lint) say so clearly instead of looking broken for Codex / Cursor users.

### First-launch notification onboarding
- Asks for OS notification permission once and sends a welcome banner so you can confirm it works. Denials are remembered — no repeat prompts.

### Smarter Usage Limits card
- Provider rate-limit and auth errors surface inline ("Rate-limited · retry in 6m") instead of the bar quietly freezing on stale data.
- The refresh button disables itself until the soonest backoff expires, then re-enables automatically.
- Cursor rows stay visible before your first message, with a hint to populate them.

## Fixes

- **macOS:** clicks inside the tray popover no longer silently dismiss it.
- **Main window reliably takes focus** when opened from the tray, instead of leaving the previous app frontmost.
- **Multi-monitor:** the popover opens on whichever display the menu bar lives on, not always the primary.
- **Windows / Linux:** the title-bar strip no longer reads darker than the rest of the panel.
- **Sidebar layout** no longer reserves macOS traffic-light gutter space on Windows / Linux.
- **Reopening the main window from the tray** now refreshes data that went stale while it was hidden. Existing content stays painted while fresh data loads in the background.
- **Claude usage limits are checked far less often** — extended cache, deduplicated concurrent calls, and skipped entirely when nothing's changed locally. Should clear up "Rate-limited" notices for users running Claude Code alongside LunoPeak.

## Platform support

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64) — deb, rpm, and AppImage

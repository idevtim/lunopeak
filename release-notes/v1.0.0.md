# LunoPeak v1.0.0

**LunoPeak is here.** The first public release of the dashboard built for the way you actually work — across every repo, every AI coding session, every config — all in one place, all on your machine.

This is the cockpit your AI-assisted workflow has been missing.

## Why you'll love it

- **Every repo and AI session, one screen.** Total spend, active sessions, dirty repos, 30-day activity — at a glance, the moment you open the app.
- **Watch your AI work, live.** Tool calls, todos, and session state stream in as it happens. No refresh button, no log diving.
- **Replay any session, end to end.** Step through every prompt, tool call, and result — with cost and token usage on every step.
- **Know exactly what you're spending.** Per-model, per-repo, per-day. Set a daily or monthly budget, get alerted before you blow past it.
- **Never hit a rate-limit cliff.** Live Claude and Codex usage windows (5-hour and weekly) so you can pace yourself instead of getting cut off.
- **Chat with your whole dev environment.** Anthropic, OpenAI, or Gemini — your choice, your keys, all stored locally.
- **Updates that just work.** A signed auto-updater keeps you on the latest release. Set it and forget it.

## What's in the box

### Activity
- **Dashboard** — totals, sparklines, quick links, provider usage windows
- **Live** — streaming tool calls and per-session todos
- **Sessions** — searchable session list with token usage, cost, and tool histograms
- **Session Replay** — full event timeline for any past session
- **Transcripts** — search every session by prompt, project, or branch
- **Costs** — per-model, per-repo, per-day spend with budget projections and alerts
- **Tools** — aggregate stats: top tools, error-prone tools, common sequences, most-edited files, top shell commands

### Code
- **Repos** — every repo under your scan paths, with branch, dirty/unpushed status, last commit, stash count, skill count, and a 30-day sparkline
- **Repo detail** — CLAUDE.md preview, attached skills, full activity
- **Work Graph** — cross-repo activity graph
- **Timeline** — chronological feed of sessions and commits
- **Diffs** — pending changes across every repo
- **Repo Pulse** — sessions and commits per repo over time

### Configure
- **Setup** — Codex config, MCP servers, plugins, per-repo completeness
- **Skills** — every Claude skill across global and repo scopes, with body preview
- **Agents** — every Claude agent with model, tools, and body preview
- **Memory** — every CLAUDE.md (global + repo) with topics, line and word counts, full body
- **Hooks** — every configured hook, scoped by repo

### Health
- **Hygiene** — actionable issues like stale branches, zombie processes, and missing CLAUDE.md files, each with a one-click fix
- **Lint** — eslint, prettier, ruff, stylelint, and editorconfig configs across repos
- **Deps** — npm, cargo, pip, poetry, go, and bundler manifest summaries
- **Env** — `.env` files surfaced with key inventory and gitignore status
- **Ports** — what's listening on what, with the owning process and working directory

### Backups
- **Snapshots** — capture and restore the dirty state of every repo at a point in time
- **Worktrees** — every git worktree across every repo, with prunable detection

### Assistant
- **Assistant** — chat with your dev environment using Anthropic, OpenAI, or Gemini. Auto-detects keys from your shell, falls back to settings.

### Settings
- Scan directories, provider and model selection, agent data sources (Claude Code, Codex)
- Cost budget with alert thresholds
- Sidebar customization — hide what you don't use
- Launch at login, automatic updates, diagnostics export

## Auto-updater

LunoPeak ships with a signed auto-updater. On first launch you'll see:

> **Check for updates automatically?** Should LunoPeak automatically check for updates? You can always check for updates manually from Settings.

With an optional *Automatically download and install updates* checkbox. Either choice is remembered. Flip both toggles any time from Settings → General.

## Platform support

- **macOS** 10.15+ (Apple Silicon and Intel) — native window vibrancy and overlay titlebar
- **Windows** 10+ (x64 and ARM64) — Mica blur on Windows 11, signed NSIS installer
- **Linux** (x86_64) — deb, rpm, and AppImage bundles for recent GTK distros

## System requirements

- Disk: ~150 MB installed
- Memory: ~120 MB resident at idle
- Network: only when you use the Assistant or check for updates — everything else stays local

## Privacy first

Local-first, end of story. No accounts, no telemetry, no analytics. The only outbound traffic is:

- Provider APIs (Anthropic, OpenAI, Gemini) when you use the Assistant
- The update endpoint, only if you opted in

## Known limitations

- The Assistant has one conversation thread — no tabs, no saved sessions, and no streaming UI yet (responses arrive in one chunk after the model finishes).
- Hygiene fixes in-app for zombie processes, stale branches, and leftover stashes; the remaining issue kinds (missing CLAUDE.md, missing `.gitignore`, ungitignored `.env`, uncommitted changes) just suggest a one-liner you run yourself.
- Session ingestion is Claude-Code-first. Codex sessions are picked up and aggregated for cost and usage, but tool calls, file edits, shell commands, branch, and the first-prompt label aren't extracted yet.

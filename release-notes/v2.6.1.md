# LunoPeak v2.6.1

Fixes for other machines: their sessions show up in Live more reliably, connection errors clear as soon as the connection works, and the one-line installer works on Linux, Proxmox included.

## What's new

- **Live shows other machines' sessions even when their process isn't found.** Live used to build each card from a running agent process, and only then attach that agent's session. When another machine's process scan missed the agent (it can on Windows), the session got no card, even though its steps appeared in the activity feed. Now any session from another machine that was active in the last ten minutes gets a card. Cards like these show no runtime or memory, since nothing reported them.

- **A machine that's off no longer slows the others down.** LunoPeak used to fetch every paired machine together and wait for the slowest. One machine that was asleep or switched off could hold up everyone else's live data by 5 seconds or more for each address it tried. Each machine now fetches on its own.

- **No more false firewall warnings.** On a busy network, one slow answer used to put "no answer … a firewall may be blocking port 47390" in Settings even while the machine showed as connected. An error now appears only after two failed checks in a row, and disappears as soon as fresh data arrives. Pairing also fetches the new machine straight away, so it shows up without waiting for the next check.

- **Easier to add a machine by address.** Some networks, many office ones included, stop computers from finding each other automatically, so Add a machine's list stays empty there. Share this machine now shows this computer's addresses, for typing on the other machine when it isn't in the Add a machine list. `lunopeak-node status` and `lunopeak-node pair` print them too. If the list is still empty after a few seconds, Add a machine says where to find the address.

- **Other machines' items are marked the same way everywhere.** A violet pill with the machine's name marks every card in Live, every step in the activity feed, every row in Sessions and, in Costs, every project row that includes another machine's spend. Projects are grouped by name, so a project you work on from two computers is one row with both machines marked. Live's header also splits the count, for example "3 sessions open (2 here, 1 on other machines)".

- **The Mac menu-bar helper can share on the network.** On macOS, Share this machine runs in the menu-bar helper. In 2.6.0 that helper was missing the settings macOS needs before it lets an app use the local network, so macOS could block it without asking. Other computers then couldn't find or reach a Mac that was sharing. The helper now has them, and macOS asks the first time.

## The installer

- **The one-line installer works on Linux again.** The 2.6.0 installer had Windows line endings, so `sh` couldn't run it, which matches the error you saw on Proxmox. The Windows build was replacing the good copy when it uploaded. 2.6.1 ships it with the right line endings, and each release now checks for this.
- **It runs on older Linux.** The Linux sharer is now built so it doesn't depend on the system's C library version. The 2.6.0 build needed a newer version than Debian 11 and Proxmox 7 have, so it wouldn't start there.
- **It installs as root.** Proxmox usually logs you in as root, and the 2.6.0 installer refused to run that way. As root it now sets up a system service that starts at boot and shares the agents run as root. Under any other user it sets up a service for that user, as before.
- **Clear advice without systemd.** On a machine without systemd, the installer explains how to keep the sharer running instead of failing.
- **The Windows installer keeps your window open.** If an install failed, it used to close the PowerShell window along with the error message.

## One thing worth knowing

- **Machines already paired by address.** If the other machine's address changes (a Parallels VM can get a new one when it restarts), LunoPeak finds it again only if it can see it on the network. Otherwise, remove it and add it again at the new address.
- **Update the Mac to reach it.** A Mac running 2.6.0 can't be reached by other machines while it shares. Update it to 2.6.1, then allow LunoPeak when macOS asks about the local network.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)

# LunoPeak v2.3.0

When Claude Code hands work to subagents, you can now watch each one: what it was asked to do, what it's doing right now, and what it cost.

## What's new

- **Live shows each subagent.** Every Claude session card now lists the subagents it has started, nested under the main chat. Each one shows the task Claude gave it, its type (Explore, Plan, a reviewer you wrote yourself), its model, and how long it's been going. A running subagent also shows its latest step, such as the file it's reading or the command it's running. Finished ones collapse to a single quiet line with how long they took, and stay for about ten minutes before they drop off.

- **"What just happened" says who did it.** Steps a subagent takes now appear in the feed alongside the main chat's, labelled with the subagent's task. Before, the feed only showed the main chat, so while three reviewers were working in parallel the feed went quiet.

- **A session with subagents still running reads as Working.** When Claude starts background subagents, its main chat goes idle while they work. Live, Home and the menu bar used to call that session Idle or Waiting for you. They now count it as working, and Home and the menu bar say how many subagents are running.

- **Sessions and replays break subagents out.** In Sessions, a row now says how many subagents a session used, and how many are working right now if it's still running. Before, you only saw this by hovering over the cost. A session replay now has a Subagents card that lists every run in the order it started, with its task, type, model, start time, length, number of steps, and cost. The session's total cost is unchanged. It already included subagent spend, and the card just shows where that money went.

- **The status line has an owl.** If you've turned on LunoPeak's Claude Code status line, it now starts with a little owl, `/{o,o}\`. While Claude is working on your turn, or its subagents still are, the owl flaps its wings. When the turn is done it sits still, so you can tell at a glance which terminal still needs a minute. To make the flapping possible, the status line now redraws once a second instead of only when something happens. LunoPeak adds that setting to your Claude Code settings the next time it opens. If you'd rather not have the owl, turn it off under Settings › Editors & terminal.

## One thing worth knowing

LunoPeak tells a running subagent from a finished one by a marker Claude Code writes when the subagent ends. If Claude Code is stopped partway through a run, that marker is never written. The subagent then shows as running for up to ten minutes after its last step, and then drops off. The opposite can happen too: a subagent stuck on one step for more than ten minutes, such as a long test run, drops off Live until its next step, though it's still working.

Claude Code doesn't tell a status line whether it's busy, so the owl works it out from the session's history. While Claude waits for you to approve a command, the owl keeps flapping, because the turn is still open.

Subagents are Claude-only for now.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)

# LunoPeak v1.13.0

Claude Opus 5.5 gets its own price, your Fable weekly limit shows up next to the others, and the Assistant can now talk to Grok. Until now LunoPeak billed Opus 5.5 as Opus 5, so if you've been running it, your Opus 5.5 spend has been reading higher than what you actually paid.

## What's new

- **Opus 5.5 is priced at its own, lower rate.** Opus 5.5 costs $4 per million input tokens and $20 per million output, down from Opus 5's $5 and $25. Cache writes follow: $5 per million for the 5-minute cache and $8 for the 1-hour one. LunoPeak had no idea Opus 5.5 was a separate model. It read the name as Opus 5 and charged the old rates, so input, output and cache writes were all about a quarter too high. Those sessions re-price themselves the next time LunoPeak reads them, so expect your Opus 5.5 numbers to come down.

- **Its cheaper cache reads are counted too.** Opus 5.5 bills cached tokens at $0.20 per million. That's 5% of its input rate, where most models charge 10%, and less than half the $0.50 it was being charged here. On a long agentic session, where most of the bill is re-reading a prompt that's already cached, this is the line that moves most. Opus 5.5 now also gets the green saving marker in Cost by model, the same one Fable 5.1 has, and the note underneath it names whichever models earned the saving.

- **Opus 5.5 is in the assistant's model picker,** right after Opus 5. Sessions labels it "Opus 5.5" now as well. It used to show up there as plain "Opus 5".

- **Your Fable weekly limit has its own bar.** Claude plans put a separate weekly cap on Fable, on top of the all-models weekly limit, and it often runs out first. LunoPeak only showed the all-models number, so you could read 30% weekly and still be cut off from Fable. Rate limits on the dashboard and the menu bar panel now show a "Weekly · Fable" bar. Its percentage and reset time come straight from Anthropic, alongside what you've spent on Fable this week. It counts toward usage alerts too, and the menu bar's warning banner calls it out by name when it's the closest limit to running out. If Fable is the limit you watch most, set it as the number shown next to the menu bar icon: Settings → System Tray → Headline window → Fable. Codex and Cursor have no Fable limit, so they show their weekly number there instead.

- **xAI is the Assistant's fifth provider.** Add an xAI API key in Settings → Assistant and you can chat with Grok 4.7, Grok 4.6 or Grok 4.5. Grok 4.7 is the default. Tool use works the same way it does with the other providers, so Grok can pull your costs, sessions and repos just like Claude or GPT can. As with every other key, it's stored in your system keychain, and requests go straight from your machine to xAI.

## One thing worth knowing

Fast mode isn't priced separately. Opus 5.5 in fast mode bills at $8 / $40 per million, twice the standard rate. The session logs LunoPeak reads don't say which speed a turn ran at, so every turn is charged the standard rate. If you use fast mode, those turns will show about half what they really cost. Opus 5 in fast mode has always worked the same way. Better to tell you than to guess.

Grok is a chat provider only for now. LunoPeak doesn't track Grok spend in Costs, because none of the tools it reads usage from record Grok token counts.

Opus 5.5 has no extra charge for long prompts. It bills the same rate across its full 1M context, so a big prompt never switches to a higher tier.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)

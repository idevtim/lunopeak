# LunoPeak v2.6.0

LunoPeak can now show your other computers next to this one: their running agents, their session history and what they cost. They connect directly over your own network, with no account and no server in between.

## What's new

- **See your other machines in Live, Sessions and Costs.** A desktop, a laptop, a build server or a Windows PC show up alongside this machine. Each card or row is labelled with the machine it came from:
  - **Live** shows their agents as they work.
  - **Sessions** lists their history, with a filter to show one machine at a time.
  - **Costs** gets an All machines / This machine switch and a By machine card, with this month's and the last seven days' spend for each computer.

- **Pair a machine with a six-digit code.** Go to Settings → Other machines → Add a machine.
  - **Finding it:** machines on your network show up in a list. Pick one, or type an address. A Tailscale address works from anywhere.
  - **Pairing:** enter the code the other machine shows. From then on the two talk over an encrypted connection that only they can use.
  - **Wrong codes:** the code works once and lasts ten minutes. After five wrong tries it stops working, and you start pairing again.
  - **Changed addresses:** if a paired machine's address changes, LunoPeak finds it again on its own.

- **Share a machine with one switch, or one line.**
  - **With LunoPeak installed:** turn on Settings → Share this machine. It keeps sharing from the menu bar when the window is closed.
  - **Without LunoPeak (a server, say):** paste one line from the README into a terminal. It installs a small sharer called `lunopeak-node`, starts it at login and shows a pairing code. It works on macOS, Linux and Windows, and runs as you, never as root or an administrator.

- **Your prompts stay where you typed them.** Other machines see which files were read and edited, which commands ran, which tools were used, and the spend. They don't see what you asked the agent or its chat replies, unless you turn on Share prompts on the machine you're sharing. Machines that share prompts are marked in Settings.

- **A shared folder works too.** If you already sync a folder between machines with Syncthing, iCloud Drive or a network share, LunoPeak can read other machines from there instead. Settings tells you if the folder is missing or nothing has been written to it yet.

## One thing worth knowing

- **Combined totals go up.** In Costs, All machines adds up every machine, so your total, today and last-seven-days figures go up by what the others spent. This machine's own numbers don't change: switch to This machine to see them on their own.
- **Some things stay this machine only.** That covers the menu bar, budget alerts and the terminal status line. Budget alerts don't count other machines' spend.
- **Replays stay on their machine.** A transcript never leaves the computer it was recorded on, so you can't replay another machine's session here. Clicking one explains that.
- **No double counting.** If a session appears both here and on another machine, it's counted once.
- **Spend lands on your days.** Another machine's spend falls on the right day in your time zone, even when that machine runs on a different clock.
- **Live status lags a little.** A machine shows as Online while LunoPeak hears from it at least every few minutes. It can take up to three minutes to show Offline after it goes to sleep.
- **Firewall prompts.** The first time you share or connect, macOS may ask whether LunoPeak can use your local network, and Windows may ask whether to allow it on private networks. Allow both.
- **First launch is slower.** LunoPeak reads your Claude Code history once more after updating, to record spend in a form other machines can line up by day.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)

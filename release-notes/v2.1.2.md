# LunoPeak v2.1.2

LunoPeak now uses Claude's new plan names and copes with Ultra's 5-hour limit going away. It also fixes a macOS bug that could damage Claude Code's saved login.

## What's new

- **Claude plans use their new names.** Anthropic renamed Max 5x to Max and Max 20x to Ultra. LunoPeak used to label both "Max plan", because Claude Code saves both under the same plan type. It now checks which tier your account is on, so a 20x account says "Ultra plan" and a 5x account says "Max plan". Prices and limits didn't change, and neither do any of your numbers.

- **Ultra's missing 5-hour limit reads "No limit".** Anthropic is removing the 5-hour limit for verified Ultra accounts. Once it's gone from yours, the "This session" meter on the dashboard and in the menu bar shows "No limit" instead of a percentage, and still shows how many tokens you've used. It never warns you that you're close to a limit you don't have. If you chose the 5-hour window for the menu bar, the menu bar shows your weekly percentage instead. Your weekly limit and your Fable limit work exactly as before.

- **Your weekly limit keeps working when the 5-hour one is gone.** LunoPeak expected Anthropic to always report a 5-hour window. Without one, it would have failed to read anything, so your weekly percentage would have gone blank too. It now reads whatever limits are there.

- **LunoPeak no longer damages Claude Code's saved login on macOS.** When your Claude sign-in expires, LunoPeak renews it and saves the new one to your Keychain for Claude Code to use. The tool it saves through quietly cuts off anything longer than about 4 KB. Claude Code's login usually stays well under that. But if you've signed in to MCP connectors in Claude Code, it saves those sign-ins in the same place, and the login can grow past that size. When that happened, LunoPeak saved a cut-off copy that neither app could read. Your Claude limits would go blank, and Claude Code could need you to sign in again. Large logins are now saved in one piece, the same way Claude Code saves them itself.

## One thing worth knowing

Anthropic is removing the 5-hour limit gradually. Newer Ultra accounts keep it until they're verified, and Anthropic emails you when yours is removed. Until then, the meter shows a percentage as usual. LunoPeak only shows "No limit" once Anthropic stops reporting a 5-hour window for your account. We built that part from Anthropic's announcement, not from an account that had already lost the limit. If it looks wrong once yours goes, please tell us.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)

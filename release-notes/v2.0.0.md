# LunoPeak v2.0.0

LunoPeak has a new look, inside and out. Every page in the main window is redesigned to answer its question in one plain sentence. The menu bar panel is rebuilt from scratch: it fits on one screen, and you can change its settings without opening the main window.

## The main window

- **Every page opens with an answer.** Each page now leads with one plain sentence under its title, for example how many tool calls your agents made this week and how that compares with last week. That sentence replaces most of the rows of stat cards. Below it, things are named in plain words, like "Ran a command", with the raw tool name or event name kept small beside them for when you need it.

- **One button per problem.** Wherever LunoPeak flags something, like a stale branch, a leftover worktree or a port still held open, it says what's wrong in a sentence and offers a single button to fix it. Anything that deletes asks first. In those confirmations Cancel is the default, so pressing Enter by habit backs out rather than deleting.

- **A sidebar you can fold.** Pages are grouped into Agent activity, Projects, Agent setup, Project health and Backups, and each group folds away. Agent setup and Backups start folded. A folded group shows the total of its badges, so you don't miss the Hygiene issue count or the number of repos with uncommitted changes. A few pages got clearer names: Deps is now Dependencies, Env is Environment, Setup is Setup checklist, and Agents is Subagents.

- **Plan usage at the bottom of the sidebar.** A small card shows each agent you track, with a bar and the percent used, highest first, and when the next limit resets. It hides on Home, which already shows your limits. In Settings you can keep it always on, show it only once something passes 70%, or turn it off.

- **⌘K to go anywhere.** "Go to…" at the top of the sidebar, or ⌘K, opens a command palette. From there you can jump to any page, take a snapshot, start an assistant chat, check for updates, export a diagnostics log, or switch between light, dark and Match system.

- **Search inside your transcripts.** The Transcripts page now searches the text of your Claude conversations, both your messages and Claude's replies, and ranks sessions by how often they match. Tool calls and their output aren't searched.

- **Clean up merged branches in one go.** A repo's page lists its branches with how far each is ahead of or behind the default branch. Branches that are fully merged get a single "Delete N merged" button. It removes only your local copies. If LunoPeak can't confirm that a branch is merged, it doesn't offer it.

- **Updates tell you when they're ready.** When an update has downloaded, a small bar at the bottom of the window says so, with a Restart button and a link to what's new. LunoPeak used to check only when it launched, so a window left open for weeks never heard about a new release. Now it checks again every six hours for as long as it's open. If you're offline, it tries again a few minutes later.

## First run

- **A short setup for new installs.** On first launch, LunoPeak finds the agents on your machine, asks where you keep your projects (and counts the repos it finds there), offers to keep your limits in the menu bar, and asks whether to warn you before you run out. If you're upgrading, you skip it and land on Home as usual.

## The menu bar panel

- **One screen, every limit.** The old panel split your providers across tabs, so checking Claude and Codex meant two clicks. Now every provider you track has its own card, stacked top to bottom. Claude and Codex cards show this session and this week side by side, with when each one resets. Cursor gets a single compact row. Each card has a status pill: "Healthy" under 70%, "Getting close" from 70%, "Almost out" from 85%.

- **A warning only when you need one.** When any limit passes 70%, a banner at the top names the provider and the limit, and says when it resets. When everything is healthy, the banner isn't there at all.

- **Fable's weekly limit folds away.** Claude's separate Fable weekly limit now sits behind a small arrow on the Claude card, to keep the card short. It doesn't stay hidden when it matters: once Fable passes 70%, or it's the limit currently holding your account, it opens on its own.

- **Running now, below the limits.** Your live Claude, Codex and Cursor sessions sit under the limits, each with how full its chat is. A busy machine scrolls this list, never the whole panel.

- **The menu bar tells you about updates.** When a new version is out, the LunoPeak owl in your menu bar gets a small download arrow in its corner. Open the panel and a banner at the top names the version, with a Restart button that installs it and relaunches LunoPeak. You don't need the main window open. The menu bar checks every six hours, even when the app has been running for weeks, and it keeps checking when you've hidden the menu bar icon. On Linux, "Restart to Update" shows up at the top of the tray menu instead.

- **Settings inside the panel.** The gear at the top slides over to the panel's own Settings. There you can choose what the menu bar shows, with a live preview of the result. You can also switch agents on and off, set limit and budget alerts, pick light or dark, and turn on open at login and automatic updates. Changes to the menu bar text show up as soon as you make them. "All settings" at the bottom opens the full Settings page in the main window.

## macOS

- **A real popover.** On a Mac the panel is now the same kind of popover macOS uses for its own menu bar items. It points at the LunoPeak icon, picks up the system's frosted material, and opens under the icon on whichever display you clicked. Clicking anywhere else closes it, and so does clicking the icon again. Light, dark and "Match system" all follow the setting, and with "Match system" the panel switches the moment you change your Mac's appearance.

- **One Keychain prompt, not two.** On a Mac, LunoPeak runs as two pieces: the main window and the menu bar. To macOS those are two separate apps, and both were asking the Keychain for the same secrets. If you have Cursor's plan usage turned on, that meant typing your password twice for the same browser cookie key. Now the menu bar alone reads your browser cookies, and the main window alone reads your saved API keys. Each secret is asked for once.

- **Restarting to update restarts all of LunoPeak.** Before, restarting from the update bar relaunched the main window but left the menu bar running the old version until you quit it. Now both come back on the new version. If you restart from the menu bar while the main window is open, the window closes and reopens on its own.

## One thing worth knowing

Update checks still follow your "Check for updates" setting, so the new badge and banner only appear when that's on. And because the menu bar's check is new in this release, you'll first see them when the version after this one comes out.

With the cookie read moved, the main window shows Cursor's plan usage from the menu bar's most recent reading. That reading refreshes every 15 minutes. If the menu bar isn't running and the last reading is more than an hour old, the main window falls back to Cursor's local data until the menu bar is back.

On Linux, the menu bar is still a plain menu, as before, so the new panel doesn't appear there.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)

# LunoPeak v1.1.0

The first feature release since launch. Codex sessions are now first-class citizens, the menu bar gained a real personality, the Assistant is one click away from every issue in your dev environment, and "Open in…" learned about every editor you actually use.

## What's new

### Open anything in any editor
- **Universal editor picker.** Every artifact row — Skills, Agents, Memory, Hooks, Live processes, Repo Detail — now has a one-click "Open" button. The first click pops a picker; subsequent clicks honor the editor you remembered.
- **Eight editors out of the box.** VS Code, Cursor, Antigravity, Windsurf, Zed, Sublime Text, VS Code Insiders, and Xcode — plus a "System default" fallback that hands the path to the OS file handler.
- **Cross-platform launching that actually works.** macOS falls back from CLI shim to `open -a "<App>"` automatically. Windows probes `.cmd`, `.exe`, and `.bat` extensions so VS Code-style shims launch even though Rust's `Command::new` doesn't honor `PATHEXT`. Linux uses the editor's CLI on PATH. Xcode is hidden on non-Mac platforms.
- **Settings → Appearance → Editors.** A clean dropdown for picking your default editor, or "Ask each time" to keep getting the prompt. Resets in one click.
- **Open the active session's folder.** Live view rows now have an "Open in editor" button next to the existing Finder reveal — sends the process's cwd into your configured editor.

### Sidebar reordering
- **Drag-and-drop within sections.** The Customize Sidebar dialog now has a drag handle on every row. Reorder routes within their section, see a blue indicator snap to the drop position, release to commit.
- **Saved order survives restarts.** A new `sidebarOrder` field in settings drives the live sidebar so your custom layout sticks across sessions.
- **Reset clears both visibility and order.** The "Reset to Default" button now wipes hidden items and reordering at once.

### Codex, fully wired up
- **Live activity reads Codex sessions.** The Live view now parses `~/.codex/sessions/**/rollout-*.jsonl` alongside Claude transcripts, so codex rows show real activity (`exec_command` → Bash, `apply_patch` → Edit) instead of borrowing whichever Claude session happened to share the folder.
- **Multi-agent live activity.** Sessions are bucketed by `(cwd, agent)`, so a Codex process and a Claude process running in the same repo each show their own last action — no more cross-contamination.
- **Codex CLI shows as "codex," not "node."** The terminal `@openai/codex` and `@anthropic-ai/claude-code` packages run as Node scripts, so the OS reports them as `node`. Live now relabels these rows using the matched argv basename.
- **Sharper AI process detection.** Process scanning now inspects argv to identify Claude Code, Codex, Cursor, and other tools, even when they're invoked through shell wrappers or with non-standard binary names.
- **Codex on by default.** New installs see Codex enabled out of the box alongside Claude Code.
- **Sessions map by PID, not cwd.** Multiple Codex/Claude instances in the same repo each get their own row instead of collapsing onto one.

### A real menu-bar app
- **Menu-bar app behaves like a menu-bar app on macOS.** Closing the window with hide-to-tray enabled now drops the dock icon entirely — no more lingering "running" dot under an app that's only meant to live in the menu bar. Reopening from the tray restores the dock automatically.
- **Reopen restores the window on macOS.** Clicking the dock icon (or `open -a LunoPeak`) now brings the main window back instead of silently no-op'ing.
- **Provider icons in the tray.** The tray menu now shows provider brand marks next to each usage window, with a refresh control so you can resync usage limits on demand without waiting for the next poll.
- **Usage reset countdown in the tray.** Each usage window shows the time remaining until reset, so you can pace work without opening the app.
- **Headline window toggle.** A new "Headline window" setting in Settings → Menu Bar lets you pin the tray percent to either the 5h session or the weekly window. Defaults to 5h since that's the one that usually matters most.
- **Tray icon stays readable on Linux.** Black-on-transparent template PNGs are inverted to white at runtime so the icon is visible on the dark panels most desktop environments default to.
- **Adaptive usage polling.** Live usage windows back off when the upstream API is quiet and tighten up when usage is changing fast. The dashboard refetches on the same 60-second cadence as the tray so the two surfaces stay in sync.

### Hygiene that means hygiene
- **"Zombie Processes" → "Background Listeners."** The section was flagging healthy long-running tools (Ollama, LM Studio, terminals, editor helpers) as zombies and offering to kill them. Renamed, demoted from warn to info, and reordered so genuine warnings lead.
- **Model runtimes excluded.** Ollama, LM Studio, and llama.cpp no longer appear in Hygiene at all — they're intentional services, not cleanup targets.
- **"Diagnose with Assistant" button.** When an Assistant key is configured, the Hygiene CTA becomes a one-click handoff: it deep-links into the Assistant with a prefilled prompt asking which issues to fix first, and the model uses its `hygiene_issues` tool to read the current list and answer.

## Security

- **API keys move to the OS keychain.** Anthropic, OpenAI, and Gemini keys are now stored in macOS Keychain / Windows Credential Manager / Linux Secret Service, with platform-specific keyring backends compiled in. Existing keys in `settings.json` are migrated automatically on first launch and the plaintext copy is wiped from disk.
- **Hardened the "Open in…" actions.** Folder names containing shell metacharacters (`&`, `|`, `>`, `"`, `\`, etc.) can no longer inject commands when launching Terminal, cmd.exe, or `claude`. Paths are now passed as separate argv elements with proper quoting on each platform.

## Fixes

- **Toggling the menu bar off no longer crashes the app.** The tray now hides through Tauri's main-thread dispatch instead of dropping `NSStatusItem` from a worker thread.
- **Auto-updater no longer chokes on a UTF-8 BOM.** The build script now writes BOM-less UTF-8 so `tauri-plugin-updater` can parse update manifests on Windows.
- **Cleaner active-process labels.** Rows show a friendlier human-readable label and resolve symlinked working directories to a stable path.
- **Package install supports alternative names** for tools whose CLI name differs from their package name.

## Platform support

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64) — deb, rpm, and AppImage

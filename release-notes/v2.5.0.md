# LunoPeak v2.5.0

Insights now shows what each pull request cost to land in Claude Code, including every attempt it took to get there.

## What's new

- **Every merged pull request shows its agent cost.** In Insights, each pull request in the merged list now has a cost on the right, with the number of Claude Code sessions behind it. The total includes the tries that didn't work: if you went back to a fix three times before it merged, all three sessions count. The cost includes subagent spend too. Pull requests that no Claude Code session worked on show a dash.

- **See the sessions behind the cost.** Click a cost to open the list of sessions that worked on that pull request's branch, oldest first. Each shows your first prompt, when it started, how long it ran and what it cost. Click one to open its replay and see what happened on that attempt.

- **Find your most expensive pull requests.** The merged pull requests card now shows the total agent spend for the period and the median cost per pull request. A Newest / Cost switch sorts the list so the priciest ones come first. This works both across all your repos and on a single repo's page.

- **A session's cost is split by branch.** If one session starts on `main` and then moves to a fix branch, only the work done on the fix branch counts toward that pull request. Work done after the pull request merged doesn't count either, so if you keep going in the same session, that spend goes to the next pull request from the branch. When only part of a session counted, its row says how much the whole session cost.

## One thing worth knowing

LunoPeak matches sessions to a pull request by its branch name, in the same repo, from before it merged. Only work from the two weeks before the pull request opened counts, and only work after any earlier pull request from the same branch name merged. That keeps a reused name like `fix-tests` from picking up old spend. Work done on a different branch, or before you created the branch, isn't counted.

Pull requests merged from the default branch, such as `main`, don't get a cost. Sessions on that branch can't be told apart from everyday work.

Costs cover merged pull requests and Claude Code only for now. Codex and Cursor don't record which branch they worked on.

The first time you open LunoPeak after updating, it reads your Claude Code history again to split costs by branch, so that first load is slower.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)

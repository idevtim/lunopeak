# LunoPeak v1.16.0

A recent Codex update changed how it saves its data, and Codex disappeared from LunoPeak. This release brings it back: limits, costs, live sessions and all. The menu bar also gets its own icon, so it stops looking like Claude's, Codex's or Cursor's.

## What's new

- **Codex is back.** Codex 0.163 compresses every conversation it saves, including all your old ones, and LunoPeak couldn't read the compressed files. Your Codex sessions dropped out of Costs and Sessions, Codex limits vanished from the menu bar and the dashboard, and running Codex sessions went missing from the Live view. LunoPeak now reads Codex's files compressed or not. Your Codex history comes back too, so expect your Costs totals to go up by your Codex spend. That number was missing; it isn't new spending.

- **Codex limits come straight from ChatGPT.** Codex used to save your 5-hour and weekly usage in a log on your Mac, and LunoPeak read it from there. As of 0.163 it no longer saves the numbers. LunoPeak now asks ChatGPT for them, the same way Codex's own `/status` does, using the sign-in Codex already has. You see the same percentages Codex would show you. They refresh every few minutes, even when Codex isn't running. That's a step up from before, when the bars only moved after a Codex turn. Turning Codex off in Settings stops LunoPeak asking.

- **The menu bar icon is LunoPeak's owl.** It used to switch to the Claude, OpenAI or Cursor logo, whichever provider was nearest its limit. With those tools running their own menu bar icons, two identical logos sat side by side and it wasn't clear which was which. The owl stays put now. Hover over it to see which provider each number belongs to.

- **Choose the text next to the icon.** Settings → Menu Bar → Menu bar text has three options: icon only, just the percentage ("42%"), or the percentage with its limit ("42% 5h", "42% Wk", "42% Fable"). The label always names the limit you're actually looking at. If you pick Fable and Codex is the provider nearest its limit, Codex has no Fable limit, so it reads "42% Wk" and doesn't claim to be Fable. The default is still just the percentage, so nothing changes unless you choose. The menu bar tooltip now names each provider's limit as well.

## One thing worth knowing

Codex limits now come from a ChatGPT address that OpenAI hasn't documented. It's the one Codex itself uses, but OpenAI could change it. If they do, or if your Codex sign-in has expired, LunoPeak falls back to the last numbers Codex saved on your Mac. Those only move when you run Codex. LunoPeak never renews your sign-in itself, because that would sign Codex out. Codex renews it the next time it runs. If you sign in to Codex with an API key, there are no plan limits to show.

Codex conversations you've archived still aren't counted in Costs. This isn't new.

Windows doesn't show text next to tray icons, so the Menu bar text option doesn't appear there. Hover over the icon instead.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)

# LunoPeak v1.2.0

A polish release. The dashboard tells you the most important thing first — what's running and what it cost today — the sidebar finally wears its own name, demo mode lives up to its name, and the Windows installer is friendlier on the way in.

## What's new

### Dashboard at a glance
- **"Cost today" stat card.** New tile alongside the existing four shows today's spend pulled from the cost feed. Goes amber when there's spend, dims to zinc when the day is free.
- **Live / Idle indicator above the date.** The header now leads with whether anything is actively running. Active sessions show as `Live · N` in emerald with a pulsing dot; quiet stretches read `Idle` in dim zinc with a static dot.
- **Motivating sub-greeting.** The randomized line under the time-of-day greeting was rewritten across all four buckets (morning / day / evening / night) — five lines per bucket, picked fresh each mount, leaning into encouragement instead of weather metaphors.

### Sidebar branding
- **LunoPeak wordmark + logo.** The sidebar now opens with the app icon and "LunoPeak" name above the Dashboard link. "Peak" is colored in the brand indigo (`#3a52a8` light / `#8497d4` dark) so the wordmark matches the marketing site.
- **Sized for legibility.** Logo at 32px, wordmark at 17px — large enough to read without crowding the navigation underneath.

### Windows installer
- **`basicUi` install mode by default.** The NSIS installer now runs with a basic UI instead of fully passive — installs still go through quickly, but users get a visible window and a progress bar instead of an apparent hang.
- **`installMode` is configurable.** New build option lets the release scripts pick between `passive`, `basicUi`, and other NSIS modes per release.
- **Version-filtered build artifacts.** Release builds now filter bundle outputs by version to avoid bundling stale binaries from previous runs into a new release.

## Platform support

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64) — deb, rpm, and AppImage
